# iJoyPaly（PRD）

## 一、核心用户与场景
- 普通用户：浏览/搜索商品→选择面值→下单支付→自动发货→自助售后。
- 运营/客服：上架商品与面值、监控订单与风控、处理退款与异常。
- 管理员：角色与权限配置、合规审计、系统参数维护。

## 二、关键业务流程
### 4.1 用户侧（前台：Quasar）
- 导航与分类：一级分类（游戏/APP/点卡）；二级分类（按充值方式/平台/应用类型等）；支持热门、推荐、促销位。
- 商品搜索：关键词（全局搜索，同一个商品，在用户端是A语言状态下能搜索B语言的）；多语言展示。
- 商品详情与校验：展示商品信息、SKU 面值与价格、地区/平台限制；下单前校验 SKU 可售性与限购规则。
- 结算与下单
  - 购物车与直购：购物车合并同 SKU 数量；加入购物车和下单前需要校验是否需要填写用户充值信息。
  - 订单预确认：计算优惠、税费（如有）、实付金额；校验与限购。
  - 创建订单：生成订单号与幂等键；可选预锁库存（短 TTL）以降低热门售罄失败。
  - 支付发起：选择支付渠道，生成待支付单并跳转/拉起；记录支付流水。
  - 订单评论：用户在订单支付后，可对订单进行评价与评分。
- 支付回调与轮询
  - 渠道回调验签→订单状态更新为已支付。
  - 轮询查询支付结果，若已支付则更新订单状态为已支付。
- 通知与消息
  - 支付成功/发码成功/退款结果通过站内信+邮件。
- 个人中心
  - 手机号/邮箱登录/注册；短信验证码校验；密码加密存储。
  - 登录后，用户中心展示订单、充值记录等。
  - 个人信息维护（如手机号/邮箱绑定、支付密码设置等）。
- 购物车管理
  - 加入购物车、查看购物车、修改购物车商品数量、删除购物车商品。
  - 购物车商品校验：是否可售、是否超过限购数量。
  - 购物车商品金额计算：根据当前购物车商品数量、商品价格、优惠、税费（如有）、实付金额。
- 订单管理
  - 订单列表展示：按状态（待支付/已支付/已取消/已退款）筛选；支持分页。
  - 订单详情：展示订单基本信息、商品列表、金额明细（优惠、税费、实付）；支付渠道、支付流水。
  - 订单操作：取消（待支付）、退款（已支付）；与支付渠道交互。

### 4.2 后台管理（前端：Element Plus）
- 商品与 SKU 维护：
  - 商品基础信息、平台/地区属性、图片与描述，多语言；SKU 面值、价格、币种与状态。
  - 上下架与可售范围控制；批量价格调整与促销。
  - 商品分类管理：一级分类（游戏/APP/点卡）；二级分类（按充值方式/平台/应用类型等）；支持热门、推荐、促销位。
  - 商品详情：
    - 商品描述（多语言/富文本）
    - 充值指南（多语言/富文本）
- 用户信息维护：
  - 个人信息（如手机号/邮箱绑定、支付密码设置等）。
  - 订单评论与评分管理（如删除、修改、审核等）。
- 订单与支付对账：
  - 订单列表与状态流转；按渠道/日期/金额对账；异常订单核对与处理。
- 语言包管理
  - 支持添加、删除、更新语言包。
  - 每个语言包包含商品名称、描述、错误提示等多语言字段。
- 货币管理
  - 支持添加、删除、更新货币。
  - 每个货币包含货币符号、汇率等字段。
  - 自动获取当前时间的汇率，用于订单金额计算。
  - 支持手动配置汇率，用于特殊情况。
- 角色管理
  - 支持添加、删除、更新角色。
  - 每个角色包含权限列表，如商品维护、用户管理、订单管理等。
- 审计与合规：
  - 高权限操作留痕；库存导入、发码、退款等关键事件审计；导出报表。
- 运营配置：
  - Banner/推荐位管理、优惠码创建与投放、活动配置。
  - 首页配置：支持配置首页展示的商品分类、推荐位、banner 广告等。
- 博文管理
  - 支持添加、删除、更新博文。
  - 每个博文包含标题、内容、图片、标签等字段。
  - 支持多语言，每个语言包包含博文标题、内容等多语言字段。

## 三、核心功能清单
### 5.1 国际化
- 支持多语言（中文-简体、中文-繁体、英文、俄文等），商品信息、描述、错误提示等。
- 管理后台可动态添加语言包
- 前端路由与组件根据语言切换。
- 后端 API 支持语言参数，返回对应语言数据。
- 数据库存储多语言字段，如商品名称、描述等。
- 前端展示时根据用户语言参数切换显示。
- 支持全局搜索，即用户当前语言为中文，但使用英文关键词也能搜索到相关商品。

### 5.2 商品目录与详情页
- 商品类目只有两级（游戏充值->全部/UID直充/账号充值/CDK；APP充值->全部/账号充值/官方直充）。
- 类目需要后台动态管理，可配置多语言，可配置是否显示等属性。
- 每个商品需要可配置用户充值信息，如充值账户/区服/角色名等。支持的前端组件类型：文本框、下拉选择框、单选框、复选框等。
- 商品SKU属性：价格、币种、限购数量（0表示无限制）、限制加购物车数量（0表示无限制）。属性需要多语言支持
- 商品SKU价格展示时根据用户语言参数切换显示，如中文展示为“¥710”，英文展示为“$100”。而且价格会有所差异。需要自动获取国际汇率+后端设置汇率，展示时根据汇率转换。

### 5.3 订单相关
- 订单创建时根据用户选择的商品 SKU 计算总金额，包含优惠、税费（如有）。
- 订单详情展示用户充值信息、商品信息、SKU 面值与价格、地区/平台标识、支付渠道、支付时间、订单号等。
- 订单状态流转：待支付→已支付→已发货/已完成（根据业务流程）。

### 5.4 支付渠道
- 支付渠道类型1：本地支付如各个国家的银行卡，当地的支付平台（有统一平台对接无需额外开发）
- 支付渠道类型2：数字货币支付如比特币、以太坊等。用户端可以选择不同的链上货币支付。（二期）
- 支付渠道需要跟货币绑定，如选择RMB，则显示支付宝/微信支付等。选择USD则显示PayPal等。
- 每个支付渠道需要配置相关参数（如 AppID、密钥、回调 URL 等）。
- 后端接收支付渠道回调（主动轮询），验证签名与参数，更新订单状态为已支付。

### 5.5 首页装修
- 首页需要展示最新商品、热门商品、推荐商品等。（可后台动态配置：标题，商品列表等）
- 轮播图管理：可后台动态配置轮播图，包括图片、链接、标题等。
- banner管理：可后台动态配置banner，包括图片、链接、标题等。

### 5.6 登录/注册
- 邮箱注册，需要发送邮件验证码
- 手机号注册，需要发送短信验证码（二期）
- 第三方登录，如twitter、facebook、google等。
- 需要接入谷歌的验证码，防止机器人注册。

### 5.7 客服系统（接入第三方）
- 需要运营可以在用户接入时直接看到用户相关信息，如订单、支付信息、售后信息等。

### 5.6 博文管理系统
- 支持添加、删除、更新博文。
- 每个博文包含标题、内容、图片、标签等字段。
- 支持多语言，每个语言包包含博文标题、内容等多语言字段。
- 支持伪静态
  
## 四、技术架构
- 后端：.NET Core 8（Web API），SQLSugar 作为 ORM，中间件实现统一日志、异常、鉴权（JWT）。
- 数据库：MySQL 5.7，读写分离可选；主键使用雪花/自增，保证幂等键（订单号、交易号）。
- 缓存：热点商品与库存状态缓存（Redis 建议），防止重复发码需加分布式锁。
- 用户端（Quasar）：统一组件库与响应式布局，SSR 可选；关键页面包括首页、列表、详情、购物车、结算、订单、账户中心、售后。
- 管理端（Element Plus）：数据表格、表单与图表为主；模块包括商品、SKU、库存批次、订单、支付、退款、风控、营销、系统。
- 图片处理：阿里云oss

## 五、部署与维护
- 服务器：centos7.6+aaPanel
- 用户端：CDN 缓存静态资源，如图片、JS、CSS 等。
